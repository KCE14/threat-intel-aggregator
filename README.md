# Threat Intel Aggregator

A CLI tool for querying threat intelligence APIs.

## Setup
1. Create `config/config.yaml`
2. Add your API keys
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `python src/main.py <IP_ADDRESS>`
